# 📁➜🐙 PocketPush

**کل یه پوشه‌ی پروژه رو، با ساختار کامل، مستقیم از گوشیت به یه ریپوی GitHub push کن — بدون ترمینال، بدون Git، بدون فایل‌به‌فایل آپلود کردن.**

هر دو نسخه از یه منطق یکسان استفاده می‌کنن و از **GitHub Git Data API** برای ساختن یه commit واحد و تمیز استفاده می‌کنن — نه چند صد commit جدا برای هر فایل.

| | |
|---|---|
| 🌐 **نسخه‌ی وب** | یه صفحه‌ی HTML تک‌فایلی، مستقیم توی مرورگر گوشی یا کامپیوتر باز می‌شه |
| 🐍 **نسخه‌ی CLI** | یه اسکریپت پایتون خالص (بدون هیچ dependency)، برای وقتی محکم‌کاری و اجرای پایدارتر می‌خوای |

---

## ✨ امکانات

- 📂 انتخاب کل یه پوشه (یا فایل zip) و push به یه ریپوی GitHub در **یه commit واحد**
- 🧹 حذف خودکار `.git`، `node_modules`، `venv`، `__pycache__`، `dist`، `build`، `.next` و فایل‌های زائد سیستمی (`.DS_Store`, `Thumbs.db`)
- 🌱 تشخیص خودکار وضعیت ریپو: خالیه؟ شاخه‌ی جدید می‌خوای؟ شاخه‌ی موجود؟ — همه‌ش خودکار هندل می‌شه
- 📁 امکان push به یه زیرپوشه‌ی خاص داخل ریپو (اختیاری)
- 🔁 مقاومت در برابر خطاهای موقتی GitHub (rate limit و تأخیر sync) با retry خودکار
- 🔒 توکن هیچ‌جا ذخیره یا ارسال نمی‌شه، فقط مستقیم به GitHub API می‌ره

## 🌐 نسخه‌ی وب — `web/pocketpush.html`

برای استفاده از گوشی یا کامپیوتر، بدون نصب هیچ‌چیزی:

1. فایل `web/pocketpush.html` رو با مرورگر باز کن (می‌تونی مستقیم دانلودش کنی، یا از طریق GitHub Pages هاستش کنی)
2. یه [GitHub Personal Access Token](https://github.com/settings/tokens/new) با دسترسی `repo` بساز (راهنمای کامل توی خود صفحه هست)
3. owner و اسم ریپو رو وارد کن
4. پوشه یا فایل zip پروژه رو انتخاب کن
5. دکمه‌ی **Push** رو بزن

توکن و اطلاعات ریپو توی همون مرورگر ذخیره می‌شن تا دفعه‌ی بعد لازم نباشه دوباره واردشون کنی.

## 🐍 نسخه‌ی CLI — `cli/pocketpush.py`

برای اجرای پایدارتر (پروژه‌های بزرگ، اتوماسیون، یا وقتی می‌خوای دقیق‌تر ببینی چی داره ارسال می‌شه):

```bash
python3 cli/pocketpush.py \
  --token ghp_xxxxxxxxxxxx \
  --owner your-username \
  --repo your-repo \
  --path ./your-project-folder
```

یا بدون هیچ آرگومانی اجرا کن، خودش مرحله‌به‌مرحله ازت می‌پرسه:

```bash
python3 cli/pocketpush.py
```

### آرگومان‌های اختیاری

| آرگومان | توضیح | پیش‌فرض |
|---|---|---|
| `--branch` | اسم شاخه‌ی مقصد | `main` |
| `--message` | پیام commit | `Upload project folder` |
| `--target-folder` | زیرپوشه‌ی مقصد داخل ریپو | ریشه‌ی ریپو |
| `--include-heavy` | `node_modules` و مشابه‌هاش رو هم آپلود کن | خاموش (نادیده گرفته می‌شن) |

نیازی به `pip install` چیزی نیست — فقط پایتون ۳ استاندارد.

## ⚙️ چطور کار می‌کنه

1. فایل‌های پوشه رو می‌خونه و مسیرها رو نرمالایز می‌کنه (بک‌اسلش، اسلش تکراری، `.git` و پوشه‌های سنگین حذف می‌شن)
2. هر فایل رو جدا به‌عنوان یه **blob** به GitHub می‌فرسته
3. یه **tree** با ساختار کامل پوشه‌بندی از روی این blob‌ها می‌سازه
4. یه **commit** از روی اون tree می‌سازه
5. شاخه‌ی مقصد رو به اون commit اشاره می‌ده (یا اگه شاخه‌ی جدیدیه، می‌سازتش)

اگه ریپو کاملاً خالی باشه (بدون هیچ commit یا شاخه‌ای)، اول با GitHub Contents API یه فایل می‌فرسته تا ریپو فعال بشه، بعد بقیه رو با روش بالا batch می‌کنه — چون Git Data API روی ریپوی کاملاً خالی کار نمی‌کنه.

## 🔒 امنیت توکن

- توکن فقط توی حافظه‌ی مرورگرت (نسخه‌ی وب) یا مستقیم به GitHub (نسخه‌ی CLI) استفاده می‌شه
- هیچ سروری بین تو و GitHub وجود نداره — همه‌چیز مستقیمه
- توصیه می‌شه توکن رو با یه تاریخ انقضای کوتاه بسازی و فقط دسترسی `repo` رو بدی
