📁⇄🐙 PocketPush

کل پوشه‌ی پروژه‌ت رو مستقیم توی یه ریپوی گیت‌هاب push کن، یا یه پوش اشتباه رو برگردون — بدون ترمینال، بدون دستور.

🚀Push کردن یه پوشه
کل یه پوشه یا zip پروژه رو با ساختار کامل روی یه ریپو push کن.
⏪بازگردانی شاخه
یه پوش اشتباه رو با برگردوندن شاخه به یه commit قبلی جبران کن.

توکن گیت‌هاب

چطور توکن بسازم؟ ▾
  1. برو به github.com/settings/tokens/new (وارد اکانتت شو اگه نیستی)
  2. توی Note یه اسم دلخواه بزن، مثلاً "pocketpush"
  3. Expiration رو هر چی خواستی بذار (مثلاً ۹۰ روز)
  4. پایین صفحه، تیک repo رو بزن (دسترسی کامل به ریپوها)
  5. پایین صفحه دکمه‌ی Generate token رو بزن
  6. یه کد سبز رنگ که با ghp_ شروع می‌شه بهت نشون می‌ده — همونو کپی کن و اینجا بچسبون (فقط همون یه‌بار نشونش می‌ده، پس همین‌جا ذخیره‌ش کن)
توکنت فقط توی همین مرورگر، روی همین گوشی ذخیره می‌شه — هیچ جای دیگه‌ای نمی‌ره.
۲

مقصد

اگه ریپو تازه ساختیش و کاملاً خالیه (هیچ commit یا README نداره)، همین main رو دست نزن — ابزار خودش تشخیص می‌ده خالیه و اولین commit رو خودش می‌سازه. فقط اگه از قبل یه شاخه‌ی دیگه (مثلاً master یا dev) داری که می‌خوای روش push کنی، اسمش رو اینجا بذار.
همین متن پیش‌فرض کاملاً کافیه، لازم نیست عوضش کنی — فقط توضیح کوتاهیه که کنار این commit توی تاریخچه‌ی ریپو ثبت می‌شه.
اگه پر کنی، کل فایل‌ها داخل همین زیرپوشه از ریپو قرار می‌گیرن، نه توی ریشه. اکثر مواقع لازم نیست پرش کنی.

انتخاب پوشه یا ZIP

اگه گوشیت اجازه‌ی انتخاب مستقیم پوشه رو نداد (مثل آیفون)، اول با اپ فایل‌های گوشی پوشه رو zip کن، بعد گزینه‌ی اول رو بزن.
پوشه‌ی .git همیشه و بدون قابل‌تغییر نادیده گرفته می‌شه، چون خود GitHub اجازه‌ی push کردنش رو نمی‌ده.
